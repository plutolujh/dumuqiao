## 1. 概述

- **项目名称**：浙江高考选科选校通
- **访问地址**：dumuqiao.hao123456.cn
- **核心定位**：面向浙江高考家长，解答"三位一体是什么"、"我孩子能报什么学校"等常见问题
- **核心价值**：工具驱动（分数定位器 + 三位一体计算器）+ 概念百科辅助理解
- **目标用户**：浙江高考考生家长（主要）+ 浙江高三/高二学生

## 2. 功能模块

收录词条：

百科采用**词条卡片式**展示，点击展开详情，支持搜索过滤。

### 2.2 三位一体综合分计算器（calculator.html）

**输入：**
- 学业水平测试等第折算分（输入A/B/C/D数量或直接输入折算分）
- 高校校测预估成绩
- 高考预估/实际分数

**输出：**
- 综合分（按各校权重比例自动计算）
- 对比裸考可降分幅度
- 参考：浙江各校综合分公式一览表

### 2.3 分数定位器（score-locator.html）

**输入：**
- 高考分数（浙江省位次或分数）

**输出：**
- 对应学校层次（省重点/二本/三本/大专）
- 各层次推荐院校列表
- PDF中提取的实际录取分数参考

### 2.4 志愿填报时间轴（timeline.html）

展示浙江志愿填报关键节点（6月25日查分 → 6月29-30提前批填报 → 7月各批次投档 → 8月征求志愿），可交互查看各节点注意事项。

### 2.5 首考策略（strategy.html）

从PDF提取的首考科目抉择建议，告知家长何时放掉科目最划算。

## 3. 技术方案

- **架构**：纯静态 HTML + CSS + Vanilla JS，无框架依赖
- **部署**：FTP/文件上传至域名根目录
- **内容存储**：每个 HTML 文件内嵌 `<script type="application/json" id="page-data">` 存储内容数据，零额外请求
- **文件结构**：
  ```
  index.html            — 首页（导航 + 工具入口）
  encyclopedia.html    — 概念百科（内嵌 terms 数据）
  calculator.html      — 三位一体计算器（内嵌 formulas 数据）
  score-locator.html   — 分数定位器（内嵌 schools 数据）
  timeline.html        — 志愿时间轴（内嵌 timeline 数据）
  strategy.html        — 首考策略（内嵌 strategy 数据）
  css/
    style.css          — 全局样式
  js/
    main.js            — 通用逻辑
  data/                — 源数据备份（JSON，供参考）
    terms.json
    schools.json
    formulas.json
    timeline.json
    strategy.json
  ```

## 4. 视觉设计

### 配色
- **主色**：浙江蓝 #1E6AB1
- **点缀色**：暖橙 #F5A623
- **背景**：白色 #FFFFFF
- **文字**：深灰 #333333

### 字体
- 思源黑体 Noto Sans SC（Google Fonts CDN）或系统默认
- 正文 16px，行高 1.6

### 风格
- 干净、权威、克制
- 卡片式布局，卡片带轻微阴影
- 不使用渐变色、不过度动画
- 给家长权威感和信任感

### 响应式
- 桌面端（1200px）+ 平板（768px）+ 手机（375px）

## 5. 内容数据来源

所有院校数据、分数段、公式均从PDF `省属家长.pdf` 提取整理。
